# Data Preprocessing Pipeline

> **Objective:** Clean, normalize, validate AST, build training samples, and split into repository-disjoint partitions.

This directory contains scripts that transform the unified raw Master Dataset (`master_samples.jsonl`) into validated training samples and repository-disjoint data splits ready for model consumption.

## Pipeline Architecture

The preprocessing pipeline is orchestrated via `run_pipeline.py`:

```mermaid
flowchart TD
    A[data/raw/master_samples.jsonl] --> B[clean_comments.py]
    B -->|master_cleaned.jsonl| C[normalize.py]
    C -->|master_normalized.jsonl| D[validate_ast.py]
    D -->|master_validated.jsonl| E[build_samples.py]
    E -->|master_semantic_samples.jsonl| H[split.py]
    H -->|80/10/10 Disjoint| J(data/splits/{train,validation,test}.jsonl)
    D -->|master_validated.jsonl| F[strip_docstrings.py]
    F -->|master_graph_ready.jsonl| G[scripts/graph/build_pdg.py]
    G --> K(data/final/master_pdg.jsonl)
```

## Files Description

- **`run_pipeline.py`**: End-to-end orchestrator that runs the entire sequence automatically.
- **`clean_comments.py`**: Removes inline comments (`#`) so the model learns from code semantics rather than natural language hints.
- **`normalize.py`**: Standardizes whitespace, line endings (CRLF -> LF), tab conversion, and indentation.
- **`validate_ast.py`**: Verifies valid Python AST syntax using 4 fallback strategies (direct, dedent, function_body, class_body).
- **`build_samples.py`**: Canonicalizes training schema (`sample_id`, `repository`, `code`, `binary_label`) and ensures unique IDs.
- **`strip_docstrings.py`**: Removes docstrings via AST NodeTransformer to prepare clean code for graph PDG extraction.
- **`split.py`**: Performs **repository-disjoint** split (80% train, 10% validation, 10% test, seed=42) and verifies zero cross-split leakage.

## Input / Output

- **Input**: `data/raw/master_samples.jsonl` (generated by `scripts/extraction/merge_all_sources.py`)
- **Output**: 
  - `data/final/master_semantic_samples.jsonl`
  - `data/splits/train.jsonl`
  - `data/splits/validation.jsonl`
  - `data/splits/test.jsonl`
  - `data/final/master_pdg.jsonl` (optional when running graph step)

## How to Run

To run the entire preprocessing pipeline with a single command:

```bash
# Full pipeline (recommended)
python scripts/preprocessing/run_pipeline.py

# Without graph PDG extraction (for semantic_only mode)
python scripts/preprocessing/run_pipeline.py --skip-graph
```
